Simple fMP4 SAMPLE-AES player

A ~700 line reduction of hls.js covering only what is needed to play a fragmented-MP4 HLS stream encrypted with METHOD=SAMPLE-AES: playlist parsing, key loading, in-band sample decryption and MSE buffering. No EME, no transmuxing, no ABR.

Sources are TypeScript; run npm run build:watch (or npm run dev) to compile ./dist/player.js before opening this page.
